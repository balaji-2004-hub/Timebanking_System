# TimeBank Frontend

## Description
The frontend application provides the user interface for the TimeBank platform.
Users can browse services, manage profiles, exchange credits, communicate with members, and access admin dashboards.

## Features
- User authentication
- Community interaction
- Messaging system
- Credit management
- Reviews and ratings
- Admin dashboard
- Responsive UI

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS

## Run Project

```bash
npm install
npm run dev
```

Frontend runs on:
http://localhost:4028

## Build

```bash
npm run build
```
