# TimeBank Backend

## Description
The backend application manages APIs and server-side logic for the TimeBank platform.

## Features
- REST APIs
- Authentication APIs
- Service management
- Credit exchange APIs
- Review system
- Admin analytics APIs

## Tech Stack
- Next.js API Routes
- TypeScript
- Node.js

## Run Project

```bash
npm install
npm run dev
```

Backend runs on:
http://localhost:4029

## API Routes
- /api/auth
- /api/services
- /api/listings
- /api/messages
- /api/reviews
- /api/credits
